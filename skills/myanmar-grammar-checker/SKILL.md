# myanmar-grammar-checker

## Planned Workflow

1. Input text နှင့် content type ကို ဖတ်ပါ။
2. Unicode/Zawgyi status ကို စစ်ပါ။
3. Spelling, grammar, spacing, punctuation အစီအစဉ်ဖြင့် စစ်ပါ။
4. certain error နှင့် recommended change ကို ခွဲပါ။
5. ပြင်ဆင်ထားသော စာသားနှင့် အကြောင်းရင်းများကို ပြပါ။

## Current Status

ဤ Skill သည် scaffold အဆင့်တွင်ရှိသည်။ အသေးစိတ် rules, references နှင့် examples များကို research ပြီးနောက် ထည့်သွင်းမည်။
