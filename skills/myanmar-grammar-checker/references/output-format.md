# Grammar Checker Output Format

## Standard Output

### စာအမျိုးအစား

- Type: formal, conversational, social, sales, technical, or unknown
- Register: written, spoken, mixed, or unknown
- Encoding status: Unicode, Zawgyi-like, mixed, or unknown

### တွေ့ရှိချက်

အမှားတစ်ခုချင်းစီအတွက်—

- Original
- Suggested correction
- Label
- Confidence
- Explanation
- Source or evidence

### ပြင်ဆင်ပြီးစာသား

အဓိပ္ပာယ်နှင့် tone မပျက်စေဘဲ စာသားအပြည့်အစုံကို ပြပါ။

### မသေချာသောအချက်များ

Context မရှိခြင်း၊ spoken/formal ကွာခြားခြင်း သို့မဟုတ် source disagreement ရှိခြင်းကို သီးခြားပြပါ။

## No Clear Error

သေချာသောအမှားမတွေ့ပါက အတင်းပြင်ဆင်ခြင်းမပြုဘဲ “သေချာသောအမှား မတွေ့ပါ” ဟု ပြပါ။ Optional style suggestion ရှိလျှင် သီးခြားခွဲပြပါ။
