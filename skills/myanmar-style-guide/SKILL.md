# myanmar-style-guide

## Scope

ဤ Skill သည် Grammar correctness ထက် document အတွင်းနှင့် project အတွင်း style consistency ကို အဓိကထား စစ်ဆေးသည်။ Business, technical, educational, social, sales/support နှင့် formal/official content များအတွက် အသုံးပြုနိုင်သည်။

## Workflow

1. Document type၊ audience၊ channel နှင့် user/brand preference ကို သတ်မှတ်ပါ။
2. [matrix.md](references/matrix.md) အတိုင်း tone၊ terminology၊ numbers/units နှင့် list style ကို စစ်ပါ။
3. အတူတူ concept အတွက် အသုံးပြုထားသော variants များကို frequency နှင့် context အလိုက် စုစည်းပါ။
4. User/brand glossary ရှိလျှင် standard source ထက် ဦးစားပေးပါ။
5. မကိုက်ညီမှုကို required change, recommended change, optional style သို့မဟုတ် context_dependent အဖြစ် ခွဲပါ။
6. [output-format.md](references/output-format.md) အတိုင်း findings နှင့် reusable style summary ကို ပြပါ။
7. User တောင်းဆိုမှသာ စာသားအပြည့်အစုံကို rewrite ပြုလုပ်ပါ။

## Guardrails

- Grammar error နှင့် style inconsistency ကို မရောထွေးရ။
- User/brand preference မရှိလျှင် အကြိုက်တစ်ခုကို universal rule အဖြစ် မကြေညာရ။
- Technical terms, product names, URLs, IDs, prices နှင့် proper names မပြင်ရ။
- Date, number, unit format ကို context မရှိဘဲ အတင်း normalize မလုပ်ရ။
- Channel-specific emoji, slang နှင့် conversational tone ကို မလိုအပ်ဘဲ မဖျက်ရ။
- Document တစ်ခုလုံး consistent ဖြစ်နေပါက အတင်းအကျပ် ပြင်ဆင်ချက် မဖန်တီးရ။
