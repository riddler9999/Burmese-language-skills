# myanmar-style-guide

## Planned Workflow

1. Document type နှင့် audience ကို သတ်မှတ်ပါ။
2. Tone, terminology, number/unit နှင့် list style ကို ရှာပါ။
3. User/brand preference ကို ဦးစားပေးပါ။
4. မကိုက်ညီမှုများကို frequency နှင့် context အလိုက် စုစည်းပါ။
5. Project အတွက် အသုံးပြုနိုင်သော style rules ကို ပြန်ထုတ်ပါ။

## Current Status

ဤ Skill သည် scaffold အဆင့်တွင်ရှိသည်။ အသေးစိတ် rules, references နှင့် examples များကို research ပြီးနောက် ထည့်သွင်းမည်။
