# Example 01 — Mixed Tone and Terminology

## Before

အသုံးပြုသူများသည် dashboard ကို စစ်ဆေးရမည်။ User က settings ပြောင်းချင်ရင် ပြောပေးပါနော်။

## Analysis

- Tone inconsistency: formal “ရမည်” and conversational “ပါနော်” are mixed.
- Terminology inconsistency: အသုံးပြုသူ and User refer to the same concept.
- Document type is unknown, so the recommendation is context-dependent.

## Option A — Business/Technical

အသုံးပြုသူများသည် dashboard ကို စစ်ဆေးရမည်။ အသုံးပြုသူက settings ပြောင်းလိုပါက အကြောင်းကြားပါ။

## Option B — Friendly Support

အသုံးပြုသူတွေ dashboard ကို စစ်ဆေးနိုင်ပါတယ်။ Settings ပြောင်းချင်ရင် ပြောပေးပါနော်။

## Note

ဘယ် version ကို ရွေးမလဲဆိုတာ target audience နှင့် channel အပေါ် မူတည်သည်။
