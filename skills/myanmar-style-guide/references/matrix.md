# Burmese Style Matrix

## Document Types

| Type | Default tone | Main priority | Typical term policy |
|---|---|---|---|
| Business | ယဉ်ကျေး၊ ရှင်းလင်း၊ တာဝန်ယူမှုရှိ | clear request, decision, next step | standard term + defined English term |
| Technical | တိကျ၊ neutral၊ concise | reproducibility and unambiguous steps | API/code terms preserved |
| Educational | ရှင်းလင်း၊ သင်ကြားပေးသော | reader comprehension | common term first, technical term explained |
| Marketing/Social | friendly, engaging, channel-native | hook, readability, CTA | brand glossary and audience usage |
| Sales/Support | polite, helpful, direct | customer intent and next action | approved product/price terms |
| Formal/Official | consistent, respectful, conservative | accuracy and accountability | approved official terminology |

## Tone Rules

- User-specified tone overrides the default matrix.
- Do not convert conversational content into formal Burmese without request.
- Do not make formal content casual merely to sound natural.
- Mixed register is a finding only when it harms clarity or contradicts the selected type.

## Terminology Rules

- User or brand glossary is authoritative for project-specific terms.
- Use one preferred term for the same concept within a document unless a distinction is intended.
- Keep technical terms in English when the Burmese translation is uncommon or ambiguous.
- Define an acronym at first use when the audience may not know it.

## Numbers, Dates, and Units

- Select one date and time format per document/channel.
- Preserve prices, IDs, dates, percentages, version numbers, and measurements.
- Do not normalize numbers solely because another format is possible.
- In tables and technical content, prefer the project-defined compact format.

## Lists and Formatting

- Use one primary list marker within a section.
- Keep list item endings consistent: all fragments, all full sentences, or all action phrases.
- Use emoji only when the selected channel or brand voice allows it.
- Do not add headings or CTA text that the user did not request.
