# Humanizer Output Format

## Standard Output

### Analysis

- Content type: [social, sales, business, technical, educational, or unknown]
- Detected patterns: [H1-H8 with confidence]
- Preservation checks: facts, numbers, names, URLs, brand terms, intent, tone

### Natural Version

ပြင်ဆင်ပြီး မြန်မာစာအပြည့်အစုံကို ထည့်ပါ။

### Change Summary

- ဘာကြောင့် ပြင်ဆင်ခဲ့သည်
- ဘယ်အပိုင်းကို မပြင်ဘဲ ထိန်းသိမ်းခဲ့သည်
- မသေချာသော အကြံပြုချက် ရှိ/မရှိ

## Short Text Mode

စာကြောင်း ၁–၂ကြောင်းသာရှိပါက detected pattern အနည်းငယ်နှင့် ပြင်ဆင်ထားသော version ကို တိုတိုပြပါ။ ပုံစံအားလုံးကို စစ်ပြီးပြီဟု မပြောရ။

## Meaning Preservation Guard

Rewrite မပြီးမီ အောက်ပါ checklist ကို စစ်ပါ။

- Facts unchanged
- Numbers unchanged
- Names and product identifiers unchanged
- URLs unchanged
- CTA unchanged unless user requests a new CTA
- Tone remains within requested level
- No new claim added

Meaning-changing edit တွေ များလွန်းပါက conservative rewrite ပြန်လုပ်ရန် သို့မဟုတ် user ကို မေးရန်လိုသည်။
