# Myanmar Humanizer Patterns

ဤ pattern များသည် လက်ရှိ MVP အတွက် empirical heuristics ဖြစ်ပြီး AI-generated text ဟု သက်သေပြခြင်းမဟုတ်ပါ။ Pattern တစ်ခုတည်းဖြင့် စာသားကို AI ဟု မဆုံးဖြတ်ရ။

## H1 — အကြောင်းအရာမတိုးသော အဖွင့်စာ

အကြောင်းအရာမစတင်မီ အထွေထွေမိတ်ဆက်စာကြောင်းများ အလွန်ရှည်လျားနေခြင်း။ Social content တွင် တိုစေနိုင်သော်လည်း formal document တွင် မဖြစ်မနေ မဖျက်ရ။

## H2 — ထပ်နေသော အနှစ်ချုပ်

ခေါင်းစဉ်၊ body နှင့် conclusion တို့တွင် အချက်တစ်ခုတည်းကို ထပ်ခါတလဲလဲ ပြောခြင်း။ မူရင်းမှာ emphasis ရည်ရွယ်ချက်ရှိ/မရှိ စစ်ပါ။

## H3 — တစ်သမတ်တည်းဖြစ်လွန်းသော စာကြောင်း rhythm

စာကြောင်းတိုင်း ဖွဲ့စည်းပုံနှင့် အဆုံးသတ်ပုံ တူနေခြင်း။ အဓိပ္ပာယ်မပျက်စေဘဲ sentence length နှင့် transition ကို သဘာဝကျအောင် ပြောင်းနိုင်သည်။

## H4 — ဘာသာပြန်ဟန်

English-style structure၊ abstract noun chain၊ မလိုအပ်သော passive phrasing သို့မဟုတ် စကားလုံးချင်းတိုက်ရိုက်ပြန်ထားသလို ဖြစ်ခြင်း။ Technical term နှင့် source meaning ကို မပြောင်းရ။

## H5 — အထွေထွေ hype စကားများ

အကြောင်းအရာနှင့် မကိုက်သော “အလွန်အရေးကြီး၊ ထူးခြား၊ အံ့မခန်း” စကားများ ထပ်ခါတလဲလဲ အသုံးပြုခြင်း။ Marketing copy တွင် ရည်ရွယ်ချက်ရှိပါက ထိန်းသိမ်းရ။

## H6 — မလိုအပ်သော formal phrasing

Social caption သို့မဟုတ် Messenger reply တွင် စာအုပ်ဆန်ပြီး အလွန်အမင်း ရိုသေ/formal ဖြစ်နေခြင်း။ User သတ်မှတ်ထားသော formality ကို မကျော်လွန်ရ။

## H7 — အကြောင်းအရာမကိုက်သော conclusion

စာသားအဆုံးတွင် အမြဲတမ်း generic summary သို့မဟုတ် CTA ထည့်ထားခြင်း။ User တောင်းဆိုမှသာ CTA ထည့်ပါ။

## H8 — Formatting အလွန်အကျွံ

ခေါင်းစဉ်များ၊ emoji များ၊ bold-like emphasis နှင့် bullet များကို content density မလိုအပ်ဘဲ အသုံးပြုခြင်း။ TikTok/Facebook format တွင် channel convention ကို ဦးစားပေးရ။

## Safe Rewrite Rules

- Facts, numbers, names, URLs, product codes နှင့် brand terms မပြောင်းရ။
- မူရင်း tone ကို အရင်ဖော်ထုတ်ပြီး ထို tone အတွင်းသာ ပြင်ရ။
- Short input တွင် pattern analysis ကန့်သတ်ထားကြောင်း ပြရ။
- မသေချာသော pattern ကို optional_style သို့မဟုတ် context_dependent ဟု သတ်မှတ်ရ။
- User က “မပြင်နဲ့” ဟု သတ်မှတ်ထားသော စာသားကို မပြင်ရ။
