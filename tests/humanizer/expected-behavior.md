# Expected Behavior

## Critical Preservation Rules

Cases H-004, H-005, H-007, H-011, H-012, and H-013 must preserve product names, prices, numbers, technical identifiers, brand names, URLs, dates, and percentages exactly unless the user explicitly asks for correction.

## Non-overcorrection Rules

Cases H-009, H-010, H-015, H-016, H-017, and H-018 must not be automatically converted into one generic formal Burmese style.

## Context Rules

Cases H-019 and H-020 require explanation of uncertainty. The Skill may offer an alternative, but must not present a preference as a certain grammar error.

## Output Rules

Every rewritten case should include:

1. Detected pattern or “no clear pattern”
2. Revised text, only when revision is justified
3. Preservation note
4. Confidence level
