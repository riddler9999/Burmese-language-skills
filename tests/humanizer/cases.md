# Humanizer Evaluation Cases

ဤ cases များသည် draft evaluation set ဖြစ်သည်။ Expected behavior တွင် rewrite လုပ်ရမည့်အရာထက် မပြောင်းရမည့်အရာကိုလည်း အလေးထားဖော်ပြထားသည်။

| ID | Type | Input signal | Expected behavior |
|---|---|---|---|
| H-001 | Social | အထွေထွေမိတ်ဆက်စာရှည် | အဖွင့်ကိုတိုစေပြီး main point ကိုစောစောထုတ် |
| H-002 | Social | “ထို့အပြင်” ထပ်ခါတလဲလဲ | မလိုအပ်သော transition လျှော့ |
| H-003 | TikTok | Hook မရှင်း | ပထမစာကြောင်းကို တိုပြီး စိတ်ဝင်စားစရာဖြစ်စေ |
| H-004 | Sales | Product name ပါ | Product name မပြောင်းဘဲ reply ကိုသဘာဝကျစေ |
| H-005 | Sales | Price နှင့် quantity ပါ | ဂဏန်းနှင့် ဈေးနှုန်း မပြောင်းရ |
| H-006 | Business | Formal paragraph ရှည် | Formal tone ထိန်းပြီး ထပ်နေသောစာကြောင်းများလျှော့ |
| H-007 | Technical | API/SDK terms ပါ | Technical identifiers မပြောင်းရ |
| H-008 | Educational | အဓိပ္ပာယ်မတိုးသော conclusion | Conclusion ကို တိုစေ သို့မဟုတ် မလိုအပ်လျှင် ဖယ် |
| H-009 | Conversational | Messenger style | Formalize မလုပ်ဘဲ သဘာဝကျမှုသာ ပြင် |
| H-010 | Informal | Slang ပါ | Slang ကို context မရှိဘဲ အမှားမသတ်မှတ် |
| H-011 | Brand | Brand name ပါ | Brand spelling မပြောင်းရ |
| H-012 | URL | Link ပါ | URL မပြောင်းရ |
| H-013 | Numbers | Date/price/percentage ပါ | Numbers နှင့် units မပြောင်းရ |
| H-014 | Mixed | Burmese-English code mix | Code/English term ကို မဖျက်ရ |
| H-015 | Natural | ရေးသားပြီးသား သဘာဝကျစာ | မလိုအပ်ဘဲ rewrite မလုပ်ရ |
| H-016 | Formal | Official announcement | Friendly tone အဖြစ် မပြောင်းရ |
| H-017 | Emoji | Social emoji သုံးထား | Emoji ကို အလွန်အကျွံသာဖြစ်မှ အကြံပြု |
| H-018 | Repetition | အလေးပေးရန် ရည်ရွယ်သော repetition | Emphasis ဖြစ်နိုင်ကြောင်း စဉ်းစားပြီး မဖယ်ရ |
| H-019 | Translationese | English structure တိုက်ရိုက်ပြန်ထား | Burmese-native alternative အကြံပြု၊ fact မပြောင်း |
| H-020 | Ambiguous | Context မရှိသော စာကြောင်းတို | Context-dependent ဟု ပြပြီး မေးမြန်းနိုင် |
